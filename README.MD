## Project: LaptopShop
-- Description: Developed a personal full-stack web application following the MVC pattern to sell laptops and accessories (currently featuring only laptops), including product management and user authentication.
- Technologies/Frameworks:
+ Backend: Java, Spring Boot, Spring Security,JPA (Hibernate), MySQL
+ Frontend: HTML, CSS, JavaScript, Bootstrap,JSP
+ Tools: Visual Studio Code, Maven, GitHub, MySQL Workbench
- Key Contributions:
+ Designed and implemented MVC controllers using Spring Boot to handle user requests and render JSP views for CRUD operations.
+ Configured JPA and Hibernate to manage data persistence with a MySQL database.
+ Built a responsive and user-friendly interface using HTML, CSS, JavaScript, Bootstrap,and JSP.
+ Integrated user authentication and authorization features for secure access.
